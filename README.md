# 🎵 Spotify Clone

A responsive music streaming web application frontend inspired by Spotify's user interface, built purely with HTML and CSS.

## 🚀 Live Demo
*(Optional: If you deploy this on Vercel or GitHub Pages, add your live link here!)*

## 🛠️ Tech Stack
* **Markup:** HTML5
* **Styling:** CSS3 (Flexbox, Grid, custom variables)
* **Icons & Assets:** FontAwesome / Custom SVGs
* **Version Control:** Git & GitHub

## ✨ Features
* **Spotify UI Design:** Authentic dark-themed sidebar, top navigation, and music library layout.
* **Responsive Layout:** Structured to adapt seamlessly across different screen sizes.
* **Interactive Elements:** Hover effects on playlist cards, play buttons, and navigation menus.
* **Music Player Footer:** Simulated bottom playback control bar with track info and volume controls.
